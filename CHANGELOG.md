# Changelog

## 0.1.0 — 2026-08-28

Initial usable MVP.

- persistent Windows/WSL workspaces
- native Codex app-server threads, turns, streaming items, reviews, diffs, approvals, and interruption
- embedded WSL terminal with Codex process API and direct-process fallback
- context packs for ChatGPT with safe workspace-scoped file loading
- Git status, IntelliJ launch, Explorer launch, reusable commands, and command palette
- secure Electron preload bridge and local JSON state
- browser mock backend, automated tests, Windows setup scripts, installer configuration, and CI workflow
